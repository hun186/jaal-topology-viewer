STEP 01 / 建立新案例

先告訴我們節點之間的關係

只需要兩欄：起點 → 終點。例如：寄件人 → 收件人、主管 → 部屬、工作 A → 工作 B。支援 parent,child／from,to／source,target／sender,recipient，亦可沒有標題列。

欄位不一樣怎麼辦？

先把關係資料存成 UTF-8 CSV，第一欄是起點，第二欄是終點。若有 count／weight 欄位，可顯示有向關係件數。

單檔 ≤ 2 MB、最多 250 個節點／2,000 條連線。檔案只在此裝置解析。

常見問題

上傳後的資料會被傳到伺服器嗎？

不會。本工作區的 CSV 讀取、圖形繪製及案例保存都在瀏覽器完成。儲存在目前網站來源（origin）的 IndexedDB，其他瀏覽器或裝置不會自動同步。

能不能只記住電腦檔案路徑？

一般瀏覽器不能靠記住本機路徑，未經授權就自動重新讀取檔案。因此本功能儲存經驗證的圖形資料，而不是路徑；也提供 JSON 備份與還原。

公司有機密資料，應該注意什麼？

共用電腦上的同一瀏覽器使用者可能開啟這些案例。請使用受控的電腦與瀏覽器個人設定檔；不需要時刪除案例，並妥善保管匯出的備份。
