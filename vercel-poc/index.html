示範範圍

此 PoC 是瀏覽器端的靜態 SVG 演示，從儲存庫虛構 CSV 產生。部門收攏按職務名稱分組，不是 Louvain 運算，也不是正式 Dash / Jaal Runtime。

正式五種 Jaal 模式、Louvain、CSV API 與 Flask 同埠功能仍由原 Python 套件提供；PoC 不連結資料庫，不上傳檔案。
